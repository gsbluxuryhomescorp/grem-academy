# Grem Academy

> Connecting the world through real estate.

A premium recruiting site for **Grem Academy** — a global real estate mastermind of 1,600+ top-producing agents operating as a community within eXp Realty.

🌐 **Live site:** https://YOURUSERNAME.github.io/grem-academy/

---

## What's inside

- ⚡ Single-file standalone HTML — no build step, no dependencies
- 🌍 Animated 3D globe medallion with traveling agent orbits
- 🤖 AI Concierge chatbot (powered by Claude)
- 🎯 Multi-step "Book a Discovery Call" lead capture
- 📊 Animated stat counters & live network map
- 🔍 Full SEO — Schema.org JSON-LD, Open Graph, Twitter cards
- 📱 Fully mobile responsive
- 🎨 Black & gold concierge aesthetic — Cormorant Garamond + Inter

## Local preview

Just open `index.html` in any browser. That's it.

```bash
open index.html        # macOS
start index.html       # Windows
```

## Deployment

This repo deploys automatically via **GitHub Pages** from the `main` branch.

Any commit to `main` updates the live site within ~30 seconds.
